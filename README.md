# Using Generative AI Tools — Boon or Bane

Course repository for REIT6811 Applied Class 6 (Activity 2). GitHub username: [jt-09](https://github.com/jt-09).

This is dummy project data for a class exercise. Identifiable participant files (signed consent, raw transcripts, photos) would go in UQ RDM, not in a public or loosely shared git repo.

## Folder structure

| Folder | What belongs here |
|---|---|
| `01_literature/` | Notes and source lists for the literature review (PDFs can live in Zotero) |
| `02_quantitative/` | Survey questions, raw CSV, cleaned CSV, analysis scripts, survey report |
| `03_qualitative/` | Interview protocol, consent *template*, dummy transcript, insights, visualisation notes |
| `04_drafts_and_reports/` | Proposal and paper drafts |
| `05_additional_materials/` | Information sheet and a media placeholder folder |

Raw survey files stay under `02_quantitative/raw/`. Cleaned files stay under `processed/`. Do not edit the raw copies.

## File naming

Use: `project_datatype_description_YYYYMMDD_version`

Example: `gai_survey_cleaned-responses_20260918_v1.csv`

## How to contribute

1. Fork or get added as a collaborator. Do not commit straight over someone else's un-reviewed work on `main` if we are using pull requests.
2. Create a branch with a short, useful name (`add-cleaned-survey`, `update-interview-protocol`).
3. Add or edit files in the matching folder, using the naming convention above.
4. Commit with a message that says what changed, for example `Added cleaned survey data and initial analysis scripts`.
5. Open a pull request into `main` and wait for review before merging.

If two people edit the same line, GitHub will flag a conflict. Fix it in the pull request, commit the resolution, then merge.
